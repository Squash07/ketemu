Sebagai bantuan, berikut pembagian area kerja proyek yang dapat dipakai untuk mengisi kolom kontribusi:

| Area | Isi |
|---|---|
| Basis data | `schema.sql`, `seed.sql`, ERD konseptual dan model fisik |
| Backend inti | Konfigurasi (`config/`), DAO (`dao/`), *service* (`service/`), filter keamanan (`filter/`) |
| Fitur pengguna | Akun, laporan barang, foto, klaim, komentar, daftar pantau, notifikasi (`web/` dan JSP terkait) |
| Fitur admin | Buku besar meja, kategori, lokasi, manajemen pengguna |
| Desain antarmuka | CSS (`assets/css/`), *tag file* (`WEB-INF/tags/`), responsivitas dan aksesibilitas |
| Pengujian dan dokumentasi | `tests/smoke-test.js`, tangkapan layar, bahan report |
| *Deployment* | Dockerfile, Render, Neon |
